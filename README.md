# An OpenTofu module to host a static site in bunny.net

[cariad/terraform-bunnynet-static-site](https://github.com/cariad/terraform-bunnynet-static-site) is an OpenTofu module that serves a static website from [bunny.net](https://bunny.net).

It's highly-opinionated and intentionally not very configurable, so read its [opinions](https://cariad.github.io/terraform-bunnynet-static-site/opinions/) before you decide to use it.

## Documentation

Read the [documentation](https://cariad.github.io/terraform-bunnynet-static-site/) to learn what the module deploys, and how to deploy it, upload your website, upgrade it, and undeploy it.
